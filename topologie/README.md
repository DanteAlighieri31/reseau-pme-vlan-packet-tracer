# Maquette Packet Tracer

Le fichier **[`arvex-reseau.pkt`](arvex-reseau.pkt)** contient la maquette construite et validée par le [cahier de recette](../docs/06-recette.md) (30/30). Pour la reconstruire, voir le [guide de construction](../docs/04-guide-construction.md).

Version de Packet Tracer utilisée : **9.0.1.0858**.

> Un fichier `.pkt` enregistré avec une version récente ne s'ouvre pas toujours dans une version plus ancienne. Indiquez la version pour que les visiteurs sachent laquelle installer.
